# PRISM symbol standard

How every PRISM (RTL viewer) symbol should look, so that **anyone studying the
schematic understands what each element is and does at a glance**. The flagship
that defines it is [`ula_mux.svg`](ula_mux.svg) — the most complex SAPHO cell
(a 42-to-1 result multiplexer) — generated by
[`scripts/prism-skin-standard.js`](../../scripts/prism-skin-standard.js).

> A skin is a netlistsvg fragment keyed by `s:type` (+ `<s:alias>` fallbacks),
> merged over the stock netlistsvg skin at compile time by `getDefaultSkinData`
> in `main/ipc/prism.js`.

## The seven principles

1. **Silhouette = meaning.** The body shape states the function before any label
   is read. A *selector/mux* is a right-pointing pentagon (flat input side →
   narrowing to one output apex). Reuse one silhouette per element class (see the
   library below) so the same shape always means the same thing.
2. **Signal flow is left → right.** Data inputs enter **west** (`s:x = 0`); the
   result leaves **east** (`s:x = width`).
3. **Control enters north.** Select / enable / mode lines come in from the **top**
   and are drawn in the **control accent (violet)**, visually separate from data.
4. **Group ports by semantic family.** A high-fan-in cell is unreadable as 40
   anonymous pins. Cluster them — exactly as the Verilog groups them — under a
   coloured family header with a bracket. **Colour encodes family, consistently.**
5. **Every pin is labelled** at its anchor, in mono, with a dot marker so wires
   visibly land. Buses carry a width hint (`[N-1:0]`).
6. **Title block.** The type name sits in the body's open zone with a one-line
   subtitle stating its nature (e.g. `42 → 1 · op[5:0]`); the instance ref floats
   in italic above the body. The full role sentence lives in the SVG comment.
7. **Theme-driven colour, crisp geometry.** Every colour is a CSS var with a hex
   fallback (themable but standalone). Integer grid, 1.5 px body stroke, 8 px row
   pitch, rounded joins.

## Colour roles

| role | token | fallback |
| ---- | ----- | -------- |
| body fill | `--prism-module-fill` | `rgba(95,224,176,.07)` |
| body stroke | `--prism-module-stroke` | `#5FE0B0` (mint) |
| type label | `--prism-module-glyph` | near-white |
| instance ref / accent | `--prism-module-accent` | mint |
| **control** (select/enable) | `--accent` | `#8E83E8` (violet) |
| pin label | `--prism-port-label` | `#8a93a6` |
| subtitle | `--text-secondary` | `#9CA1AE` |

## Silhouette library (body shape per element class)

| class | shape | examples |
| ----- | ----- | -------- |
| selector / mux | right-pointing pentagon + select notch | `ula_mux`, `norm_mux`, `mux` |
| ALU / datapath op | pentagon with operand V-notch + result arrow | `ula`, `ula_add`, `ula_fmlt` |
| register / latch | rectangle with a clock-edge triangle on `clk` | `pc`, `stack`, `dff` |
| memory | rectangle with a stacked-plates edge | `mem_data`, `mem_instr` |
| decoder / control | rectangle, control ports north, fanned outputs east | `instr_dec`, `addr_dec`, `io_ctrl` |
| FIFO / buffer | rectangle with flow chevrons | `myFIFO` |

## Hard rules (don't break these)

- **`s:pid` MUST equal the Verilog port name exactly** — it's what ELK routes to.
- **Exclude `` `ifdef YANC_SIM_VIS `` ports** (the sim-visibility taps like `sim`).
  yosys reads the HDL without that define for PRISM, so an anchor for a port that
  isn't in the netlist makes ELK abort with *"Referenced shape does not exist"*.
- Keep `s:type` + every `<s:alias>` so PRISM keeps matching the cell.

## Authoring / rolling out

The standard is executable. Describe a module as a spec (families of
`{name, bus}` + the select/output) and call `renderSymbol(spec)` in
`scripts/prism-skin-standard.js`; the same routine draws them all, so the whole
datapath stays one consistent family.

```sh
node scripts/prism-skin-standard.js            # (re)write the flagship ula_mux.svg
node scripts/prism-skin-standard.js --print    # dump to stdout
```

**Preview** any skin on the PRISM dark theme by wrapping it in an HTML page that
defines the `--prism-*` / `--aurora-*` vars and giving the `<svg>` a `viewBox`,
then screenshotting with a headless browser (the design above was tuned that
way). The hand-crafted symbols (`core`, `ula`, `processor`, `instr_dec`,
`addr_dec`, `myFIFO`) and the auto-baselines from `gen-prism-skins.js` are the
backlog to bring up to this standard, one class at a time.
